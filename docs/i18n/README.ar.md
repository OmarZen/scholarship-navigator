# 🎓 Scholarship Navigator: دليلك للمنح الدراسية

### لاقي المنح اللي تقدر تكسبها فعلاً، وماتفوّتش أي ميعاد تاني.

أداة **مجانية ومفتوحة المصدر**. بتشتغل لوحدها أو جوه مساعد الذكاء الاصطناعي بتاعك (Claude، Cursor، Codex، Gemini...)، وتقدر تكلمها بالعربي عادي.

[English README](../../README.md)

## المشكلة

كل سنة آلاف الطلاب الكويسين بيضيعوا منهم منح ممولة بالكامل. غالباً مش علشان مستواهم ضعيف، لكن علشان:

- عرفوا بالمنحة **بعد ما الميعاد عدى**؛
- تعبوا أسابيع في منحة **مكانوش مؤهلين ليها أصلاً** (الجنسية أو السن أو التخصص)؛
- كان **ناقصهم ورقة واحدة**: جواب توصية، أو IELTS خلصت صلاحيته، أو شهادة من غير توثيق؛
- المعلومات متفرقة في **بوستات قديمة** ورسايل واتساب.

**Scholarship Navigator بيحل ده:** بتحكي عن نفسك مرة واحدة، وهو بيراجع كل الشروط، ويديك درجة توافق، ويقولك
الورق الناقص بالظبط، ويعملك خطة بمواعيد حقيقية.

## بيعمل إيه؟

| | |
|---|---|
| ✅ **الأهلية** | بيراجع الجنسية (بالقوايم الرسمية)، والإقامة، والسن، والدرجة العلمية، وعمر الشهادة، وسنين الخبرة، والتخصص، وشرط الرجوع للبلد. ولو فيه معلومة ناقصة بيقولك "محتاج مراجعة" ويوضح المطلوب. |
| 📊 **درجة توافق من ١٠٠** | المعدل مقارنة بالحد الأدنى والمستوى التنافسي لكل منحة، واللغة، والخبرة، والتخصص، والقيادة، والأبحاث، وتفضيلاتك. وكل نقطة ليها شرح. |
| 📄 **الورق الناقص** | إيه اللي معاك، وإيه الناقص، كل ورقة بتاخد وقت قد إيه، تبدأ امتى، وكمان بينبهك لو ورقة صلاحيتها هتخلص قبل الميعاد. |
| 🗓️ **خطة بمواعيد** | المهام محسوبة بالعكس من آخر ميعاد لكل منحة، والورقة المطلوبة في كذا منحة بتبقى مهمة واحدة. |
| 🧭 **برامج إيراسموس موندوس** | ٥٦ برنامج، ولكل برنامج الدول والجامعات اللي بتدرس فيها، وحالته، وميعاد ٢٠٢٧. بتختار لحد ٣ برامج، وكل اختيار بيتعمل له خطاب نية خاص بيه. |
| 📁 **مجلد شخصي** | مجلد لكل منحة فيه مسودات المقالات والخطابات بأسئلة المنحة نفسها. وشغلك عمره ما يتمسح. |
| 📈 **Excel وتقرير وتقويم** | لوحة متابعة، ونسبة جاهزية بتتحدث لوحدها، وتقرير HTML، وملف تقويم فيه تذكيرات. |
| 🌍 **بعد القبول** | حاسبة التكاليف والحساب المغلق، ومعادلة الشهادات والتوثيق، والفيزا والسكن، ودليل الدراسة والشغل في ١٨ دولة. |

## إزاي تبدأ؟

```bash
git clone https://github.com/OmarZen/scholarship-navigator.git
cd scholarship-navigator
python3 -m venv .venv && .venv/bin/pip install -e ".[mcp]"
```

بعدها عندك طريقتين:

**١. مع مساعد ذكاء اصطناعي (أسهل):** افتح المجلد في Claude Code أو Cursor، أو ضيف سيرفر MCP (الطريقة موجودة في الـ README الإنجليزي)، واكتب مثلاً:

> "ساعدني ألاقي منحة ماجستير ممولة بالكامل في أوروبا. اسألني الأسئلة المطلوبة الأول."

**٢. من غير مساعد:**

```bash
.venv/bin/python cli.py assess
```

هيسألك شوية أسئلة، وبعدها يعملك مجلد `output/<اسمك>/`. افتح فيه ملف `INDEX.md` وملف الإكسيل اللي في `reports/`.

## المنح الموجودة

**٣٥ منحة** في ٢٨ دولة، غير المنح اللي بتغطي كذا دولة، ومنهم:
تشيفنينج، وجيتس كامبريدج، ورودس، وإيراسموس موندوس، وDAAD، وإيفل، والمنحة المجرية، والمعهد السويدي، والدنمارك، وفنلندا، وإيطاليا، وأيرلندا، وهولندا، وبلجيكا، والنمسا، والتشيك، وبولندا، وإسبانيا، وسويسرا، وفولبرايت، وأستراليا، ونيوزيلندا، واليابان MEXT، وكوريا GKS، والصين CSC، وتايوان، وتركيا، وMBZUAI، وKAUST، وسنغافورة، وماستركارد، وIntra-Africa.

**٥٦ برنامج** إيراسموس موندوس وIntra-Africa في **٣٧ دولة**: هندسة، وطاقة، وذكاء اصطناعي وبيانات، وأمن سيبراني، وروبوتات، وفوتونيات، وكم، ومواد، ونووي، وزراعة، وتصميم.

القوايم كاملة: [المنح](../SCHOLARSHIPS.md) · [البرامج](../PROGRAMS.md)

كل ميعاد وكل قايمة دول ليها **مصدر رسمي وتاريخ تحقق** (آخر مراجعة كاملة: أكتوبر ٢٠٢٦).

## أسئلة شائعة

**مجانية؟** أيوه، رخصة MIT، من غير حسابات ولا إعلانات.

**بتقدم بدالي؟** لأ. بتقولك تقدم فين، وإيه الناقص، وتبدأ امتى، وبتكتبلك المسودات. والتقديم نفسه بتعمله إنت على المواقع الرسمية.

**بياناتي آمنة؟** كل حاجة بتفضل على جهازك في مجلد `output/`. والأداة عمرها ما بتطلب رقم الباسبور أو الرقم القومي أو بيانات البنك.

**المواعيد مضمونة؟** كل ميعاد مكتوب جنبه هو إيه: **مؤكد** (إنت اتأكدت منه)، أو **منشور** (من المصدر الرسمي)، أو **تقديري** (على حسب نمط كل سنة). اتأكد دايماً من الموقع الرسمي قبل ما تقدم.
